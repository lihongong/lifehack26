# Use a versioned hard-coded NUS Zone graph

The first release will model Kent Ridge and UTown as ten hard-coded NUS Zones: UTown, Museum/UCC, CDE, Central, FASS, Business, Computing, PGP, Science, and Medicine/Kent Ridge MRT.
Nearby means the same zone or one edge in a versioned undirected adjacency graph inferred from official NUS geography and transport information, not an official walking-time claim.
Moderators may assign posts and unknown aliases to existing zones, while adding zones or graph edges requires a reviewed code change.
