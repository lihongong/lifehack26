# Gate live Source Feeds on permission

The first release will use seeded demonstration data and direct in-app reports, because broad or unauthorized Telegram aggregation creates access, consent, retention, and deletion risks.
Each live Source Feed must remain disabled until its chat administrators give written permission and the feed passes a privacy review covering displayed fields, retention, attribution, corrections, and deletion.
An original author's identity or contact link may be displayed only through an approved, revocable consent mechanism.
When that consent is withdrawn, the imported identity and content must be removed promptly, leaving at most a non-identifying deletion record.
Source Discrepancies must enter Moderator review instead of being resolved silently.
