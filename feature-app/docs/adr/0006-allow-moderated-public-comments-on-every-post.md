# Allow moderated public Comments on every post

Marketplace Listings, Buffet Posts, Lost-Item Posts, and Found-Item Reports will all accept public Comments because community context may help resolve availability, freshness, and ownership questions.
Comments will use public display names, support one reply level, and allow author editing and deletion with removed-parent placeholders.
Every Comment can be reported or hidden by a Moderator, while Ownership Evidence and other private claim details must remain outside Comments.
