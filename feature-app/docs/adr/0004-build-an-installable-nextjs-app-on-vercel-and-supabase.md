# Build an installable Next.js app on Vercel and Supabase

The product will be a mobile-first installable web app built with TypeScript and Next.js, hosted on Vercel, and backed by Supabase PostgreSQL, managed authentication, and object storage.
Domain rules will remain in framework-independent modules, the Gem Ledger will be append-only, and Playwright will verify end-to-end behavior.
Production data and server-side functions will use the providers' Singapore regions where available to reduce latency and support the product's data-location goals.
